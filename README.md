# 🧮 FlowChart Calculator Switch

**FlowChart로 간단한 계산기 로직을 설계하고 Java로 구현한 연습 프로젝트입니다.**

---

## ✅ 시나리오: 간단한 계산기 시스템

- 사용자는 두 개의 숫자와 하나의 연산자를 입력한다.
- 연산자는 `+ , - , * , /` 중 하나이다.
- 프로그램은 입력된 값의 유효성을 검사한 후 계산 결과를 출력한다.
- 정상적으로 계산이 완료되면 프로그램을 종료한다.

## 📌 입력 / 출력 정리

### 입력(Input)
- 첫 번째 정수 `num1`
- 연산자 `operator` (`+ , - , * , /`)
- 두 번째 정수 `num2`

### 출력(Output)
- 계산 결과 `result`

### 상태(State)
- `num1` : 첫 번째 숫자  
- `num2` : 두 번째 숫자  
- `operator` : 연산자

---

## 🔎 조건 정리

### 종료 조건
- 계산 결과 출력 후 프로그램 종료

### 분기 조건
- 연산자에 따른 계산 처리  
  - `+` : num1 + num2  
  - `-` : num1 - num2  
  - `*` : num1 * num2  
  - `/` : num1 / num2  

### 예외 / 에러 조건
- 연산자가 `+ , - , * , /` 가 아닌 경우  
  → `"잘못된 입력입니다."` 출력 후 다시 입력받기  
- 나눗셈에서 `num2 == 0` 인 경우  
  → `"0으로 나눌 수 없습니다."` 출력 후 다시 입력받기  

---

## 🔁 로직 흐름 설계

1. 시작 시 한 번만 실행
   - 없음

2. 반복
   1) `num1`, `operator`, `num2`를 입력받는다.  
   2) 연산자가 `+ , - , * , /` 인지 확인한다.  
      - 아니오 → `"잘못된 입력입니다."` 출력 후 다시 입력받기  
   3) 연산자가 `/` 인 경우 `num2 == 0` 인지 확인한다.  
      - 예 → `"0으로 나눌 수 없습니다."` 출력 후 다시 입력받기  
   4) `switch` 문으로 연산을 수행한다.

3. 종료 시
- 계산 결과 출력  
- 프로그램 종료
